# Prueba física para cerrar el reto

El software, los datos ambientales y las evidencias de ejecución ya están incluidos. Falta confirmar una condición real de movimiento del participante.

1. Abre el laboratorio local y coloca la laptop sobre una mesa. Mantén el router y el receptor fijos.
2. Crea una captura de 60 segundos, nombre `Quietud 1`, condición **Quietud**. Permanece quieto; anota si otras personas se mueven. Quietud no significa habitación vacía.
3. Crea otra de 60 segundos, nombre `Cruces 1`, condición **Caminando**. Cruza varias veces entre el router y la laptop. No muevas la laptop.
4. Repite ambas condiciones otras dos veces. Conserva todos los resultados, incluso si no detectan diferencias.
5. Descarga los CSV y toma una captura mientras la gráfica se actualiza. Registra lo que hiciste realmente y las interrupciones observadas.

No etiquetes cruces de la trayectoria si no sabes dónde está el router. Usa un punto de acceso conocido para ese experimento.

Después se comparan ventanas válidas, salidas del algoritmo y condiciones anotadas. Se documentan errores y falsos indicios; no se promete exactitud a partir de una sola captura.

Para Skybrush también faltan la copia de repositorio asignada por VantTec y el tutorial del show real.
